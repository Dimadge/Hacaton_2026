Название проекта: «Альфа.Навигатор».
PostgreSQL 16 запускается через Docker Compose.
Перед запуском нужно скопировать .env.example в .env и задать пароль.
Команда запуска: docker compose up -d db.
Команда проверки: docker compose ps.
Подключение: docker compose exec db psql -U alfa_admin -d alfa_navigator.
Рабочая схема: alfa.
Первоначальная структура: 20 таблиц.
SQL выполняется автоматически только при первой инициализации.
Демо-пользователи пока не создаются.
Расширенный скоринг ещё требует дополнения модели данных.
Для остановки без удаления данных: docker compose down.
