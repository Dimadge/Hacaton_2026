# Чек-лист сдачи хакатона

Согласно предоставленному сообщению организаторов, **26 октября 2026 года, 18:00** — дедлайн отправки всех материалов. Проверить актуальный часовой пояс и точный адрес формы сдачи в личном кабинете хакатона.

## Что должно быть в репозитории

- [ ] Финальный коммит отправлен в `main`, получен `git rev-parse HEAD`; SHA указан в README или поле сдачи.
- [ ] Репозиторий **приватный**, GitHub-аккаунту `alfa-hack-2026` предоставлен доступ на чтение (по условиям организаторов).
- [ ] `README.md` первым экраном описывает продукт и главное отличие, даёт запуск, учётки, тестовый сценарий, ссылки на схемы.
- [ ] Docker и `docker compose` воспроизводимо запускают **весь** проект на обычном ПК (8–16 ГБ RAM без GPU).
- [ ] `frontend/package-lock.json`, зависимости Python и версии образов зафиксированы в репозитории; Python-зависимости заданы диапазонами, **полный lock для них не реализован** — честно указать как ограничение или добавить lock отдельно.
- [ ] Безопасный `.env.example` присутствует; `.env`, токены, SQL-дампы, настоящие пароли и секреты **не входят** в Git.
- [ ] Пример синтетических данных создаётся через `seed` и SQL-инициализацию.
- [ ] Документирован пароль клиента (`DEMO_CLIENT_PASSWORD`) и банкира (`DEMO_BANK_PASSWORD`) как переменные окружения, а не опубликованные секреты.
- [ ] Есть `THIRD_PARTY_NOTICES.md` с моделью внешних имитаций.
- [ ] Есть архитектурная диаграмма, API/Swagger, импортируемая коллекция, state machine, ER-диаграмма, тестовый план.
- [ ] Зафиксированы **наблюдавшиеся** результаты, а не выдуманные проценты эффекта.
- [ ] Если используется открытая LLM — отмечено, что она локальная, необязательная и ее лицензия проверяется отдельно.

## Проверка перед нажатием «Отправить»

```bash
git status --short
git diff --check
git rev-parse HEAD
git check-ignore .env
git ls-files .env
docker compose ps -a
docker compose exec -e DEMO_SIGNING_CODE_VISIBLE=true api python -m pytest -q
```

Вторая строка команды `git ls-files .env` должна ничего не выводить. **Нельзя делать `git push --force` на общую ветку.**
